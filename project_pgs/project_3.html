Overview

The Grinder Remote Monitoring System was built around the idea of using IoT to monitor the average uptime of our tungsten shot grinders at Tungsten Parts Wyoming. This project utilized an IoT device that wired into the grinder's power switch. The device would then send a signal on the local network to a Raspberry Pi that was utilizing a Python script, SQL, and a web based API to store the data. This webservice could be accessed remotely over the internet so our management team could gather necessary reports on what machines caused the most issues.

Features

  • A Wi-Fi based IoT sensor directly connecting the Local Network to the Grinder's Power.
  • A Python code that deciphered an MQTT message with JSON style packets of data and stored them in a database.
  • A separate Python code would upload the databased information to the Web API for data visualization.
